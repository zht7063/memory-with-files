# 0025 写入前 secret 扫描

- 状态：已接受（2026-11-20）

## 决定

- 每个写命令在落盘前扫描**本次新增**的内容（与写入前的页面相比），命中即拒绝（`SECRET_DETECTED`），不落盘。
- 报错只给规则名、行号与打码样本，绝不回显原文。
- 没有任何绕过开关（参数、环境变量、配置都不行）。
- 规则沿用 1.x：云厂商 / 代码托管 / 支付平台 API key、私钥、JWT、带密码的 URL、高熵的 `key = value` 赋值。
- 扫描器是纯计算，位于 `mwf-domain`（或其子模块），`mwf lint` 复用同一套规则检查存量页面。
