# 0047 检索基准的参考页面大小

- 状态：已接受（2026-11-21）；细化 [0011](0011-search-in-memory-bigram.md)、[0021](0021-testing.md)

## 背景

0011 与 0021 要求 5000 页的检索基准守住约 100 ms，但没有规定页面多大。每次检索都现建索引，耗时随语料总量线性增长。在 4 vCPU 的 orb 上（2026-11），5000 页（拉丁词与随机汉字各半）“建索引 + 一次检索”的中位数为：每页约 0.5 KB 时 84–91 ms，约 1 KB 时 193–196 ms，约 1.8 KB 时 375–429 ms。

## 决定

- 100 ms 的目标以**每页约 0.5 KB**（标题、summary、标签与正文合计）的 5000 页为参考，对应 `mwf-search` 基准中正文 2 组句子的一档。
- 基准保留约 1 KB、约 1.8 KB 两档，只作参考，不作为门槛。
- 暂不做多线程建索引，也不引入索引缓存；若实际页面普遍更大、检索明显变慢，再按 0011 另立 ADR。

## 后果

- 页面较大或数量更多的项目，一次检索可能在 100–400 ms 之间。
- 基准数字记录在 [crates/mwf-search.md](../crates/mwf-search.md)。
