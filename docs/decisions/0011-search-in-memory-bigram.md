# 0011 BM25 索引在内存中现建；CJK 用字二元组分词

- 状态：已接受（2026-11-20）

## 决定

1. 每次检索时读取全部页面，在内存中构建 BM25 索引，**不写任何缓存文件**。若实测单次检索超过约 100 ms 再考虑缓存（届时另立 ADR）。
2. 分词器自写，位于 `mwf-search`：
   - 拉丁文字按 Unicode 词边界切分并转小写；
   - 中日韩文字按字二元组（bigram）切分；
   - 不引入词典分词（如 jieba-rs）。

## 后果

- 没有派生索引，就没有过期、刷新、加锁问题。
- 两字中文词（部署、迁移）可以命中。
- 需要一个基准测试（例如 5000 页）守住性能假设。
