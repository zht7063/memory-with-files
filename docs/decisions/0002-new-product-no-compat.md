# 0002 Rust 版作为全新版本，不兼容 1.x

- 状态：已接受（2026-11-20）

## 决定

Rust 版不承诺与 TS 1.x 的任何兼容：`.mwf/` 磁盘格式、CLI 命令与参数、MCP 工具、错误码、hook 输出均可重新设计。不做 1.x → Rust 版的数据迁移承诺（是否提供一次性导入工具另议）。

不做"TS / Rust 行为对等"验证；Rust 版在不含 TS 代码的孤儿分支上开发（见 [0010](0010-orphan-branch-v2.md)）。

## 后果

- 每一项 1.x 功能都需要重新决定"要不要、怎么做"，记录在 open-questions / ADR 中，而不是默认继承。
- 1.x 的设计（锁、去重、预览 token、secret 扫描……）可作为参考，但不是约束。
